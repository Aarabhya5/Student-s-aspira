AARABHYA LEARNING — COMPLETE CLICKABLE PROTOTYPE

HOW TO RUN
1. Extract this ZIP.
2. Keep all files in the aarabhya-learning folder.
3. Open index.html in Chrome or Edge.

INCLUDED
- 26 separate HTML pages across Public, Student, Teacher and Admin portals.
- Responsive purple, gold and diamond-inspired theme.
- Working navigation.
- Local demo workflows: tasks/homework, notes, courses, exams, demo user management, analytics, demo tutor responses and demo role selection.
- Database schema, backend starter notes and deployment checklist in docs/.

IMPORTANT LIMITATIONS
This is a local browser prototype. LocalStorage is not secure authentication or a cloud database.
The tutor response is a demonstration, not live AI.
Do not put private student data into the demo.
For real deployment, configure a secure backend, database, authentication provider, access-control rules, server-side AI API key, backups and HTTPS. Since student users may be minors, obtain parent/guardian and appropriate institutional oversight before real-world launch.
